# Agent icon sources

- Claude Code: Claude mark from the official Claude Code wordmark at https://claude.com/product/claude-code
- Codex: OpenAI mark from https://openai.com/favicon.svg
- OpenCode: official OpenCode brand asset from https://opencode.ai/brand

The macOS client renders these vector marks as semantic template images so they
remain legible in light mode, dark mode, and selected controls.
